# Chess Lesson Availability Calendar

A fun, chess-themed availability picker for Doug to mark the days and times he's free to teach Mahlet how to play chess.

## Features

- Interactive month calendar with a chessboard look — click a date to open its time slots.
- Click or drag across time slots (7 AM–9 PM, 30-minute blocks) to mark yourself available, "Mark whole day free," or clear a day in one click.
- Live summary of everything that's been scheduled, with one-click removal per day.
- **Download Calendar (.ics)** — exports the selected times as a standard calendar file that can be imported into Google Calendar, Apple Calendar, Outlook, etc., and shared with Mahlet.
- **Download This App** — saves the whole page as a single self-contained HTML file, so it can be reopened offline with no server or internet connection required.
- Everything is saved to the browser's local storage, so refreshing the page won't lose your picks.

## Usage

Open `index.html` in any modern browser (double-click it, or serve it with any static file server). No build step, dependencies, or installation needed.
